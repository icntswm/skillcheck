---
name: find-bug
description: Investigate any problem with tests or code. Use when a test fails, including tests that fail only sometimes, pass on retry or fail only in CI, when an endpoint returns an error, a service crashes or a stack trace needs explaining.
---

1. Reproduce the failure and read the full error.
2. Form one hypothesis at a time and check it against the code and logs.
3. Report the cause with evidence before proposing a fix.
