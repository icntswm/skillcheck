---
name: find-bug
description: Find the root cause of a failure that happens every time. Use when a test fails consistently, an endpoint returns an error, a service crashes or a stack trace needs explaining ("why does X fail", "where does this error come from").
---

1. Reproduce the failure and read the full error.
2. Form one hypothesis at a time and check it against the code and logs.
3. Report the cause with evidence before proposing a fix.
